# AgroClimatic

Nursery research app for forest-seedling production: greenhouse climate, seed lots, sowing
batches, germination, growth, treatments, mortality, provenance, instrument calibration, and
randomised trials with analysis of variance. Written entirely in Python with
[Streamlit](https://streamlit.io).

## Run it

Python 3.11 or newer.

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app opens at http://localhost:8501. On first start it creates `data/agroclimatic.db`
(SQLite) with three reference species and a set of example records (batches, climate
readings, germination counts, growth measurements and an RCBD substrate trial) so every tool
can be explored. Examples are labelled in the app and can be removed in **Settings**. Set
`AGROCLIMATIC_EXAMPLES=0` to start empty.

## Deploy

**Streamlit Community Cloud** (free): sign in at https://share.streamlit.io with GitHub,
choose **Create app**, pick this repository and branch, and set the main file to `app.py`.
Add secrets (below) under the app's **Settings → Secrets**.

Its disk is temporary: the database is reset whenever the app restarts or redeploys. Download
a backup in **Settings** regularly, or run the app on a server with a persistent disk (any host
that can run `streamlit run app.py`; set `AGROCLIMATIC_DB` to a path on that disk).

Everyone who can open a deployed app shares one database. For a public URL, set
`APP_PASSWORD` so only your team can use it.

## Configuration

Environment variables, or `.streamlit/secrets.toml` (template: `.streamlit/secrets.toml.example`).

| Name | Purpose |
|---|---|
| `AGROCLIMATIC_DB` | Database file (default `data/agroclimatic.db`) |
| `AGROCLIMATIC_EXAMPLES` | `0` to skip example records on first start |
| `APP_PASSWORD` | Optional shared password for the whole app |
| `GEMINI_API_KEY` | Optional. Enables AgroBot open questions, AI trial-design suggestions and germination interpretation. Calls are made from the server, so the key is not sent to browsers |
| `GEMINI_MODEL` | Default `gemini-flash-latest` |

Without a Gemini key, AgroBot answers from your records and a small built-in reference.

## Structure

```
app.py                     navigation, page config, optional password
app_pages/                 one file per screen
agroclimatic/
  science/calculations.py  germination, seedling quality, climate, fertigation formulas
  science/trial_design.py  seeded CRD / RCBD / Latin square / split-plot randomisation
  science/anova.py         ANOVA, Tukey HSD, compact letters, assumption tests
  data/schema.py           pydantic models: units and valid ranges for every record type
  data/store.py            SQLite storage; every write is validated first
  data/backup.py           JSON backup and restore
  data/seed.py             reference species and example records
  services/                Gemini client; record summaries for AgroBot
  ui/                      shared Streamlit helpers and chart styling
tests/                     pytest suite
scripts/                   generators for the SciPy / statsmodels reference values
```

Data model:

```
Species ─< SeedLot ─< Batch ─< germination counts, growth measurements, fertigation,
                              pest observations, pre-sowing treatments, mortality,
                              irrigation, leachate tests
Greenhouse ─< bench placements ─> Batch
Experiment ─< trial variables (one value per plot)
```

## Science

- **Germination** (definitions as in Ranal & Santana 2006): final germination %, mean
  germination time Σ(tᵢnᵢ)/Σnᵢ, speed index Σ(nᵢ/tᵢ) (Maguire 1962), germination energy as
  % germinated by day 7 after sowing.
- **Seedling quality**: sturdiness quotient H/D, shoot : root dry-mass ratio, Dickson quality
  index (Dickson, Leaf & Hosner 1960), relative growth rate (ln W₂ − ln W₁)/Δt.
- **Climate**: VPD from the Tetens equation, dew point (Magnus form, same constants), daily
  light integral, growing degree days (simple average method).
- **Fertigation**: product mass for a target ppm, leaching fraction, ΔEC of leachate.
- **Trial layouts**: reproducible from a stored seed (mulberry32 generator, Fisher–Yates
  shuffle). Layouts saved by the earlier JavaScript version reproduce exactly.
- **Trial analysis**: fixed-effects ANOVA for CRD (unequal replication allowed), RCBD, Latin
  square and split-plot (main plots tested against error (a), sub-plots and A × B against
  error (b)); Tukey HSD / Tukey–Kramer from SciPy's studentized range distribution with
  compact letter display (Piepho 2004); CV; Shapiro–Wilk and Brown–Forsythe tests on
  residuals, with residual and normal Q–Q plots.

Results are tested against hand-worked values and against SciPy 1.17 / statsmodels 0.15
reference output (`tests/*-reference.json`, generated by `scripts/`).

## Backup and moving from the earlier version

**Settings → Download backup** saves every record as JSON; **Restore** validates each record
and adds or updates it by id. Backups made by the earlier React/Android version of
AgroClimatic use the same format and import unchanged (covered by a test).

## Development

```bash
pip install -r requirements-dev.txt
ruff check . && ruff format --check .
pytest -q
```

The tests include headless runs of every page (`streamlit.testing`), form submissions and
the example trial's analysis. CI (`.github/workflows/ci.yml`) runs lint and tests on Python
3.11 and 3.13 for every pull request.
